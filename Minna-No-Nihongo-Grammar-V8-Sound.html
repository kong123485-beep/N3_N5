初級 I（第 1～12 課）

JLPT N5 基礎句型
課數核心文法與句型重點常見例子 / 說明
第 1 課名詞肯定、否定、疑問句；助詞「の」〜は〜です / じゃありません / 〜か
第 2 課指示代名詞（事物）これ / それ / あれ / この〜 / その〜 / あの〜
第 3 課指示代名詞（場所）；價錢詢問ここ / そこ / あそこ / いくらですか
第 4 課時間表達；動詞「ます形」現在與過去式〜時〜分 / 〜ます / 〜ません / 〜ました
第 5 課移動動詞；交通工具與時間點助詞へ行きます / で来ます / に帰ります
第 6 課他動詞與受詞助詞「を」；邀約表現〜を食べます / 〜ませんか / 〜ましょう
第 7 課工具與語言助詞「で」；授受表現（給予/接收）箸で食べます / あげます / もらいます
第 8 課い形容詞與な形容詞的基本肯定與否定大きいです / 静かです / どんな〜
第 9 課喜好、能力、擁有的助詞「が」；原因「から」〜が好きです / 上手です / 分かります
第 10 課存在動詞「います・あります」與位置詞〜に〜がいます / あります / 上・下・中
第 11 課數量詞、期間與頻率表達ひとつ / 一人 / 一週間に〜回
第 12 課名詞與形容詞過去式；比較級與最高級暑かったです / 静かでした / 〜より〜ほうが

課數核心文法與句型重點常見例子 / 說明
