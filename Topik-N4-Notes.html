🇯🇵 日文 N4 文法

可能形

能夠做

話せる 講到 / 食べられる 食到

口訣：一類變え段，二類加られる

〜つもり / 〜ようと思う

打算

明日行くつもり 聽日打算去
〜てみる

試下做

食べてみる 試下食
てあげる / てもらう / てくれる

幫人 / 叫人幫 / 人幫我

教えてあげる 教你 / 教えてもらう 叫人教我 / 教えてくれる 佢教我
〜てほしい

想要對方做

来てほしい 想你嚟
たら / ば / と / なら

如果 / 一...就

雨が降ったら、行かない 落雨就唔去 / 春になれば 變春天就
ので / のに

因為 / 雖然

病気なので、休みます 病咗所以休息 / 勉強したのに、落ちた 溫咗但肥佬
〜すぎる

太... / 做過頭

食べすぎた 食太多
そうだ / らしい / みたい

聽講 / 好似

雨が降るそうだ 聽講會落雨 / 子供みたい 好似細路
はず / かもしれない / なければならない

應該 / 可能 / 必須

来るはず 應該會嚟 / 雨かもしれない 可能落雨 / 行かなければならない 必須去
ようになる / ことになる

變得能夠 / 決定咗要

話せるようになった 變到識講 / 転勤することになった 決定咗要調職
より / 方が〜 / 〜ておく / 〜てしまう

比較 / 預先做 / 唔小心做咗

日本より韓国が好き 韓國好過日本 / 買っておく 買定先 / 忘れてしまった 唔小心唔記得咗
